# 공식 스코어 사용자 수정 불가

## 결정

직관/집관 기록의 승/패/무는 **KBO 동기화 스코어로만** 계산한다. 사용자가 점수를 임의 수정하지 못하게 한다.

## 배경

- 초기 설계에는 사용자 스코어 수정 필드(`is_score_modified`)가 있었음
- 잘못된 승률·`승리요정` 타이틀, 데이터 신뢰도 하락
- 앱 가치 = "공식 결과 + 내 관람 기록" 조합

## 구현

- `attendance_records.my_team_score`, `opponent_score`, `result`는 서버가 `games` 스코어로 계산
- UI: 스코어·결과 **읽기 전용** 안내
- 내 팀이 아닌 경기: `cheered_team_id`로 어느 팀 기준 승패인지 결정

## 예외

- 스코어 미동기화 경기: result null, 승률 집계에서 제외 또는 무승부 처리 정책 적용
- 취소 경기: 별도 집계 (취소요정 등 부가 타이틀)
