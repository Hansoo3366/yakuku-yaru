# 요구사항

## 과제/학습 요구사항 매핑

| 과제 요구사항 | 구현 내용 |
|--------------|----------|
| 로그인 | 이메일/비밀번호 JWT 로그인, `HttpOnly` 쿠키 |
| 회원가입 | 이메일 중복 검사, Gmail SMTP 인증번호, bcrypt 암호화 |
| 게시판 | 후기 게시판 CRUD, 검색, 페이징 |
| 댓글 | 댓글 작성/조회/삭제, 댓글 알림 |
| CRUD | 게시글, 댓글, 직관/집관 기록, 내 팀, 알림, 관리자 데이터 |
| 페이징 | 게시글 목록 페이지네이션 |
| 파일 업로드 | 직관 사진, 프로필 사진, WebP 최적화 |
| DB 관계 | 사용자, 팀, 경기, 선수, 기록, 동행자, 게시글, 댓글, 알림 |
| Swagger | REST API 문서화 |
| Docker | Web/API/MySQL/Caddy 프로덕션 구성 |

## 핵심 비즈니스 요구사항

### 인증 (Auth)

- 이메일/비밀번호 회원가입
- 이메일 중복 검사
- Gmail SMTP 기반 인증번호 발송
- bcrypt 비밀번호 저장
- JWT 로그인 + 인증 API 보호
- 비밀번호 재설정

### 야구 도메인

- 회원가입 시 **내 팀** 1개 설정, 마이페이지에서 변경
- 팀 로고·컬러 기반 UI 테마
- KBO 일정/결과/순위/선수/선발/라인업 동기화
- 월간 캘린더에서 내 팀/전체 경기, 직관/집관, 기록 있는 날 필터
- 경기 상세: 예매처, 선발 투수 스탯, 라인업, 구장 정보
- 직관/집관 기록 CRUD, 사진·메모, 동행자 태그
- **공식 스코어 기준** 승/패/무 (사용자 수정 불가)
- 직관 승률 50% 이상 시 `승리요정` 타이틀

### 커뮤니티

- 게시판 CRUD, 검색, 페이징
- 댓글 CRUD, 내 글 댓글 시 앱 내부 알림
- XSS 방지용 입력 정제

### 운영

- 관리자: 사용자/게시글/댓글/KBO 데이터/응원가 관리
- PWA 설치 가능
- 프로덕션 HTTPS 배포

## 제약 조건

- KBO **공식 공개 API 없음** → 웹 페이지·브라우저 호출 데이터 파싱
- 업로드 파일은 서버 Docker volume (Object Storage 미연동)
- 실시간 푸시 알림 미구현
- 단일 VM 배포 → 배포 시 짧은 중단 가능

## 우선순위

1. **Must**: 인증, 게시판, 캘린더, 직관 기록, Docker 배포
2. **Should**: KBO 동기화, 동행자, 승률/타이틀, PWA
3. **Could**: 응원가, 구장 가이드, 관리자 고도화
4. **Won't (현재)**: 결제, 푸시 알림, 무중단 배포
