# 기능 목록

## 인증·계정

| 기능 | 설명 | 상태 |
|------|------|------|
| 회원가입 | 이메일, 비밀번호, 닉네임, 내 팀 선택 | ✅ |
| 이메일 인증 | 6자리 인증번호, 만료·재발송 | ✅ |
| 로그인/로그아웃 | JWT + httpOnly Cookie | ✅ |
| 비밀번호 재설정 | 토큰 기반 reset | ✅ |
| 프로필 수정 | 닉네임, 프로필 사진 | ✅ |
| 내 팀 변경 | 마이페이지에서 favorite team 변경 | ✅ |

## 캘린더·경기

| 기능 | 설명 | 상태 |
|------|------|------|
| 월간 캘린더 | 경기·기록 통합 뷰 | ✅ |
| 필터 | 내 팀/전체, 직관/집관, 기록 있는 날 | ✅ |
| 오늘 이동 | PC sticky 필터 + 모바일 FAB | ✅ |
| 경기 카드 | 시간, 매치업, 스코어, 취소 사유, 선발 투수 | ✅ |
| 경기 상세 | 선발 스탯, 라인업, 예매, 알림, 구장 정보 | ✅ |
| 팀 순위 | KBO 순위 동기화 표시 | ✅ |
| 취소 경기 UI | 우천/황사/그라운드/폭염/한파/기타 아이콘 | ✅ |

## 직관·집관 기록

| 타이틀 | 승리요정, 구장별·상황별 부가 타이틀 | ✅ |
