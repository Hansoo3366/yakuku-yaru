# 게시판

## 개요

직관 후기 등 **자유 게시판**. 과제 요구사항 CRUD + 검색 + 페이징 + 댓글 + 알림.

## API

| 메서드 | 경로 | 설명 |
|--------|------|------|
| GET | `/posts` | 목록 (검색, page, limit) |
| GET | `/posts/:id` | 상세 |
| POST | `/posts` | 작성 (인증) |
| PATCH | `/posts/:id` | 수정 (본인) |
| DELETE | `/posts/:id` | 삭제 (본인/관리자) |
| GET | `/posts/:id/comments` | 댓글 목록 |
| POST | `/posts/:id/comments` | 댓글 작성 |
| DELETE | `/comments/:id` | 댓글 삭제 (본인) |

## 권한

- 작성·댓글: 로그인 필수
- 수정/삭제: `user_id === req.user.id` (관리자 예외)

## 보안

- `sanitizePlainText` — HTML/script 제거
- rate limit — 글쓰기·댓글 API
- 렌더링: plain text (dangerouslySetInnerHTML 미사용)

## 알림

내 글에 댓글 → `post_commented` → 작성자 `notifications`

## UI

- 목록: 제목, 작성자 프로필, 댓글 수, 날짜
- 상세: 본문 + 댓글 + 하단 입력
- React Hook Form + Zod 검증
