# 승리요정 타이틀

## 개요

직관 경기 중 **응원 팀 승리 비율**이 50% 이상이면 `승리요정` 타이틀 표시. 재미·동기부여 요소.

## 승률 계산

```typescript
// winCount / (winCount + loseCount + drawCount) × 100, 소수 1자리
function calculateStatsWinRate(win, lose, draw) {
  const total = win + lose + draw;
  return total ? Math.round((win / total) * 1000) / 10 : 0;
}
```

## 집계 대상

| 포함 | 제외 |
|------|------|
| 직관(stadium) 기록 | 스코어 없는 경기 (result null) |
| 수락된 동행 직관 | 집관 (별도 통계) |
| 공식 스코어 기준 승패 | 취소만 있고 결과 없는 경우 |

## 타이틀 종류 (일부)

| 타이틀 | 조건 예시 |
|--------|----------|
| 승리요정 | 직관 승률 ≥ 50% |
| 패배요정 | 직관 승률 < 50% (유사) |
| 구장별 | 잠실 N회, 사직 N회 등 |
| 상황별 | 1점차, 케네디, 투수전 등 |

`resolveAttendanceTitle`, `resolveAttendanceTitles` — `apps/web/src/lib/attendance-score.ts`

## 표시 위치

- 마이페이지 (`/me`)
- 홈 통계 카드
- `HonorTitleSwiper` 컴포넌트

## 설계 이유

- 사용자 입력 스코어 금지 → 타이틀 신뢰도 유지
- 직관만 승률에 사용 → "직관 요정" 컨셉 강화
- 동행 수락분 포함 → 함께 간 경기도 인정
