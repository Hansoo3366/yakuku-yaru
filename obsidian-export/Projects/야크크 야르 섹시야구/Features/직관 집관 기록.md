# 직관·집관 기록

## 개요

경기별로 **1건**의 관람 기록. 직관(`stadium`) / 집관(`home`), 사진, 메모, 동행자, 공식 스코어 기반 승패.

## API

- `POST /attendance-records` — 생성
- `PATCH /attendance-records/:id` — 수정
- `DELETE /attendance-records/:id` — 삭제
- `POST /attendance-records/:id/photo` — 사진 업로드

## 비즈니스 규칙

| 규칙 | 설명 |
|------|------|
| 1경기 1기록 | `UNIQUE(user_id, game_id)` |
| 응원 팀 | 내 팀 경기면 생략, 아니면 `cheered_team_id` 필수 |
| 스코어 | `games` 테이블 값으로 서버 계산, UI 읽기 전용 |
| 사진 | 클라 WebP 리사이즈 → 서버 sharp → `/uploads` |
| 권한 | 소유자 수정/삭제, 수락 동행자는 정책에 따라 편집 가능 |

## 승패 계산

```
응원 팀 점수 vs 상대 점수 (공식 스코어)
→ win / lose / draw
스코어 없음 → result null, 승률 집계 제외
```

## UI

- 작성: `/attendance/new?gameId=`
- 수정: `/attendance/[recordId]/edit`
- 캘린더: 해당 날짜 썸네일 또는 배지
- 경기 상세: 티켓형 기록 카드
