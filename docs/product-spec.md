# Product Spec

## Overview

야크크 야르~ 섹시야구는 KBO 팬이 직관/집관 기록을 캘린더에 남기고, 사진, 메모, 동행자, 공식 경기 결과를 함께 관리하는 모바일 친화형 PWA 웹앱입니다.

## Goals

- 사용자가 내 팀을 설정하고 경기 일정을 쉽게 확인한다.
- KBO 일정, 결과, 선발 투수, 라인업 데이터를 캘린더와 경기 상세에 반영한다.
- 직관/집관 기록을 사진과 메모 중심으로 빠르게 남긴다.
- 동행자를 태그하고, 수락된 동행 기록을 각자의 캘린더에 반영한다.
- 직관 승률과 `승리요정` 타이틀로 재미 요소를 제공한다.
- 로그인, CRUD, 게시판, 댓글, 페이징, DB 관계, Swagger, Docker, 배포 흐름을 모두 경험한다.

## Non Goals

- 실제 결제 또는 티켓 예매 기능은 구현하지 않는다.
- KBO 공식 실시간 중계 수준의 데이터 정확도와 지연 없는 갱신을 보장하지 않는다.
- 브라우저 푸시 알림은 현재 범위에 포함하지 않는다.
- Native 앱 또는 Flutter 앱으로 구현하지 않는다.

## Target Users

- KBO 경기를 자주 보러 가는 팬
- 직관/집관 기록을 사진과 함께 모으고 싶은 팬
- 내 직관 승률을 확인하고 싶은 팬
- 동행자와 같은 경기 기록을 공유하고 싶은 팬

## Main User Flow

1. 사용자가 회원가입 중 응원 팀을 선택하고 이메일 인증을 완료한다.
2. 로그인 후 캘린더에서 내 팀 경기 일정을 확인한다.
3. 경기 상세에서 예매처, 예매 오픈 시간, 선발 투수, 라인업, 구장 정보를 확인한다.
4. 경기 관람 후 직관/집관 기록을 만들고 사진과 메모를 등록한다.
5. 같이 간 회원을 동행자로 태그한다.
6. 태그된 회원은 알림에서 수락 또는 거절한다.
7. 캘린더와 마이페이지에서 기록, 동행 배지, 승률, 타이틀을 확인한다.

## Required Study Features

### Auth

- 이메일/비밀번호 회원가입
- 이메일 중복 검사
- Gmail SMTP 기반 이메일 인증번호 발송
- bcrypt 기반 비밀번호 암호화 저장
- JWT 로그인
- 비밀번호 재설정
- 인증이 필요한 API 보호

### Board

- 로그인한 사용자만 게시글 작성 가능
- 본인이 작성한 글만 수정/삭제 가능
- 게시글 목록, 상세, 작성, 수정, 삭제
- 게시글 목록 검색과 페이징
- 게시글 작성자 프로필 이미지 표시

### Comment

- 로그인한 사용자만 댓글 작성 가능
- 본인이 작성한 댓글만 삭제 가능
- 게시글 상세에서 댓글 조회
- 내 글에 댓글이 달리면 앱 내부 알림 생성

## App-Specific Features

### Team Setting

- 사용자는 회원가입 시 한 개의 응원 팀을 설정한다.
- 사용자는 마이페이지에서 응원 팀을 변경할 수 있다.
- 팀 로고를 회원가입, 캘린더, 경기 상세, 마이페이지, 게시판 프로필 영역에서 활용한다.
- 선택한 팀의 컬러를 주요 버튼, 네비게이션, 캘린더 보조 배경에 accent로 적용한다.

### Calendar

- 월간 캘린더를 제공한다.
- 내 팀 경기와 전체 경기를 전환할 수 있다.
- PC/tablet에서는 캘린더 필터 영역을 sticky로 유지하고 `오늘` 이동 버튼을 제공한다.
- 모바일에서는 하단 필터 dock과 오늘 이동 FAB를 제공한다.
- 경기 카드에는 시간, 매치업, 스코어, 구장, 선발/예상 선발 투수를 간결하게 표시한다.
- 취소 경기는 사유별로 구분한다. 우천취소는 비 아이콘, 황사/미세먼지 취소는 먼지 아이콘, 그라운드/폭염/한파/기타 사유는 별도 상태로 표시한다.
- 직관/집관 기록이 있는 날짜는 사진 썸네일 또는 기록 배지를 표시한다.
- 동행자가 수락한 기록은 `동행` 배지로 표시한다.

### Attendance Record

- 사용자는 경기별 직관/집관 기록을 작성할 수 있다.
- 내 팀 경기라면 응원 팀을 따로 선택하지 않아도 된다.
- 내 팀 경기가 아닌 경우에만 응원 팀을 선택한다.
- 공식 스코어가 있는 경기는 기록의 승/패/무를 자동 계산한다.
- 스코어는 사용자가 직접 수정하지 않는다.
- 사진, 메모, 관람 유형, 동행자 목록을 저장한다.
- 업로드 이미지는 형식/용량 제한을 거치고 WebP로 최적화한다.
- 기록에는 최종 수정자를 저장한다.

### Player and Game Center Data

- KBO 선수 조회 페이지를 기반으로 선수 마스터 DB를 구축한다.
- KBO 경기센터 데이터를 기반으로 경기별 선발 투수, 선발 투수 스탯, 라인업을 저장한다.
- 캘린더에는 `선발` 라벨로 양 팀 선발 투수를 표시한다.
- 경기 상세에는 선발 투수 프로필 이미지, 평균자책점, WHIP, WAR, 경기 수, 선발 평균 이닝, QS를 표시한다.
- 경기 상세에는 양 팀 라인업, 타순, 포지션, 선수 프로필, WAR를 표시한다.

### Winning Fairy Title

- 직관 경기 중 응원 팀 승리 수 / 직관 경기 수로 승률을 계산한다.
- 동행자로 수락한 직관 기록도 내 캘린더와 승률 인사이트에 반영한다.
- 승률이 50% 이상이면 `승리요정` 타이틀을 표시한다.
- 마이페이지에서 전체 기록, 직관, 집관 통계를 분리해 보여준다.

### Game Reminder

- 사용자는 경기 상세에서 경기 알림을 설정하거나 해제할 수 있다.
- 현재 버전에서는 앱 내부 알림 설정 상태만 저장한다.
- 실제 브라우저 푸시 알림은 추후 확장 기능으로 둔다.

### Companion Tags and Notifications

- 사용자는 직관/집관 기록에 다른 회원을 동행자로 태그할 수 있다.
- 태그된 회원은 알림을 받고 `수락` 또는 `거절`을 선택한다.
- 수락한 기록만 동행자의 캘린더에 노출된다.
- 동행자가 응답하면 호스트에게 결과 알림을 보낸다.
- 호스트는 기록 수정 화면에서 동행자별 응답 상태를 확인할 수 있다.

### Stadium Guide

- 경기 상세에서 구장별 맛집 메모와 주차 정보를 확인할 수 있다.
- 공통 구장 정보는 seed 데이터로 관리한다.
- 사용자는 구장별 개인 맛집/주차 메모를 저장할 수 있다.
- 지도 API 연동 전까지는 외부 지도 링크를 제공한다.

### Board and Community

- 게시글 목록은 제목, 작성자, 댓글 수, 게시 날짜를 중심으로 컴팩트하게 표시한다.
- 게시글/댓글 작성자 프로필 이미지를 표시한다.
- 게시글과 댓글은 스크립트/CSS 삽입을 막기 위해 입력 정제와 렌더링 정책을 적용한다.
- 주요 생성/수정 API에는 rate limit을 적용한다.

### Admin

- `/admin`은 관리자 권한 사용자만 접근할 수 있다.
- 관리자는 사용자 목록/검색/역할 변경/삭제를 할 수 있다.
- 관리자는 게시글과 댓글을 조회하고 삭제할 수 있다.
- 관리자는 경기, 구장, KBO 데이터 관리 화면을 통해 운영 데이터를 점검한다.

## Current Limitations

- KBO는 공식 공개 API가 없으므로 웹 페이지와 브라우저 호출 데이터를 기반으로 동기화한다.
- 외부 구조 변경 시 파서 수정이 필요하다.
- 업로드 파일은 현재 서버 로컬 Docker volume에 저장한다.
- 이메일 발송은 SMTP 설정이 없으면 운영 환경에서 동작하지 않는다.
- 단일 VM 배포 구조라 배포 중 짧은 중단이 발생할 수 있다.
