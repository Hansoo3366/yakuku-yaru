# Product Spec

## Overview

야크크 야르~ 섹시야구는 야구 팬이 직관한 경기를 캘린더에 기록하고, 사진과 스코어, 메모를 함께 남길 수 있는 모바일 친화형 PWA 웹앱입니다.

## Goals

- 사용자가 내 팀을 설정하고 경기 일정을 쉽게 확인한다.
- 직관한 경기의 사진, 스코어, 메모를 빠르게 기록한다.
- 캘린더에서 직관 기록을 시각적으로 확인한다.
- 직관 승률과 `승리요정` 타이틀로 재미 요소를 제공한다.
- 과제 필수 요구사항인 로그인, CRUD, 게시판, 댓글, 페이징, DB 관계, Swagger, Docker 흐름을 모두 경험한다.

## Non Goals

- 초기 버전에서 실제 결제 또는 티켓 예매 기능은 구현하지 않는다.
- 초기 버전에서 실시간 푸시 알림은 필수가 아니다.
- 초기 버전에서 KBO 공식 데이터 자동 연동은 필수가 아니다.
- Native 앱 또는 Flutter 앱으로 구현하지 않는다.

## Target Users

- KBO 경기를 자주 보러 가는 팬
- 직관 기록을 사진과 함께 모으고 싶은 팬
- 내 직관 승률을 확인하고 싶은 팬

## Main User Flow

1. 사용자가 회원가입 후 로그인한다.
2. 내 팀을 설정한다.
3. 캘린더에서 내 팀 경기 일정을 확인한다.
4. 경기 상세를 열어 예매처와 예매 오픈 시간을 확인한다.
5. 직관 후 사진, 메모, 스코어를 등록한다.
6. 캘린더에서 업로드한 사진 썸네일을 확인한다.
7. 마이페이지에서 직관 승률과 타이틀을 확인한다.

## Required Study Features

### Auth

- 이메일/비밀번호 회원가입
- 이메일 중복 검사
- 이메일 인증
- bcrypt 기반 비밀번호 암호화 저장
- JWT 로그인
- 인증이 필요한 API 보호

### Board

- 로그인한 사용자만 게시글 작성 가능
- 본인이 작성한 글만 수정/삭제 가능
- 게시글 목록, 상세, 작성, 수정, 삭제
- 게시글 목록 페이징

### Comment

- 로그인한 사용자만 댓글 작성 가능
- 본인이 작성한 댓글만 삭제 가능
- 게시글 상세에서 댓글 조회

## App-Specific Features

### Team Setting

- 사용자는 한 개의 응원 팀을 설정할 수 있다.
- 내 팀 기준으로 캘린더 경기 일정을 필터링한다.

### Calendar

- 월간 캘린더를 제공한다.
- 내 팀의 경기 일정을 날짜별로 표시한다.
- 직관 기록이 있는 날짜는 사진 썸네일을 표시한다.

### Attendance Record

- 사용자는 경기별 직관 기록을 작성할 수 있다.
- 직관 사진, 메모, 스코어, 결과를 저장한다.
- 저장된 기록은 수정/삭제할 수 있다.

### Score

- 경기 기본 스코어는 `games` 테이블에서 불러온다.
- 사용자가 직접 수정한 스코어는 직관 기록에 저장한다.
- 수정 여부를 `is_score_modified`로 관리한다.

### Winning Fairy Title

- 직관 경기 중 내 팀 승리 수 / 직관 경기 수로 승률을 계산한다.
- 승률이 50% 이상이면 `승리요정` 타이틀을 표시한다.

## Open Questions

- 이메일 인증은 실제 SMTP를 사용할지, 개발용 토큰 방식으로 먼저 구현할지 결정이 필요하다.
- 경기 일정 데이터는 초기에는 seed 데이터로 넣을지, 관리자 입력 화면을 만들지 결정이 필요하다.
- 사진 저장소는 서버 로컬 디스크로 시작할지, 추후 Object Storage로 확장할지 결정이 필요하다.
